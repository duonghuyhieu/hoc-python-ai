# Python AI 80 ngày — code theo video

Code của từng video trong series «Python AI 80 ngày» trên kênh Hiếu học mỗi ngày. Mỗi ngày một thư mục: README ghi bạn học gì, từng đoạn code trên video kèm lệnh chạy và kết quả máy đã chạy thật, câu đố, đáp án câu đố hôm trước và bài tập.

Cập nhật code mới: `git pull`.

## Cài đặt

Python 3.12 (python.org). Mỗi máy làm một lần:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Chạy bài: `python ngay-01/buoc_1.py`.
